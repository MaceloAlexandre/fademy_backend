<!-- Backend contracts (Plans 01-02) the frontend consumes. -->

POST /api/conversations  body { userId: targetUserId } -> 201|200 { conversation: { _id, memberIds[], ... } } | 400 self | 403 not-mutual/blocked/cross-institution | 404 no-user
GET  /api/conversations  -> 200 { conversations: [ { _id, memberIds:[{_id,name,avatarUrl}], updatedAt, lastMessage:{text,mediaUrls,createdAt}|null } ] }
GET  /api/notifications  -> 200 { notifications:[ { _id, type, read, actorId:{...}, refId, refModel, createdAt } ], ... } — for message_received, refId IS the conversationId and refModel is 'Conversation' (Plan 02 contract). Used here to derive unread conversation set.
GET  /api/conversations/:id/messages?cursor&limit -> 200 { messages:[...], hasMore, nextCursor }  (consumed in Plan 04)
POST /api/conversations/:id/messages (multipart: text, images[]) -> 201 { message }  (consumed in Plan 04)
Socket: io(url, { auth: { token } }); server emits 'message:new' (a Message doc) to the recipient's per-user room.
