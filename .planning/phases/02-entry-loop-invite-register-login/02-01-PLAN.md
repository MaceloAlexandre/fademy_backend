## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Elevation | createInvite roleTarget | mitigate | Only admin may mint roleTarget='admin' (D-07); checked in controller before persist (403 otherwise) |
| T-02-02 | Elevation | POST /api/invites by aluno | mitigate | requireRole gate excludes 'aluno' → 403 before controller (INVT-04) |
| T-02-03 | Information Disclosure | cross-tenant invite access | mitigate | createInvite sets institutionId from req.user only; revoke scoped to req.user.institutionId; never from body |
| T-02-04 | Tampering | invite token guessing | mitigate | token = crypto.randomUUID() (122 bits entropy, unguessable); closed/expired/revoked invites rejected on lookup (D-06) |
| T-02-05 | Denial of Service | unbounded maxUses | mitigate | Slot cap enforced per roleTarget (D-04); reject over-cap with 400 |
