Backend API (Plans 01-03):
- GET /api/invites/:token → { roleTarget, institution name, remainingSlots, valid, reason } (public)
- POST /api/media/presign { contentType, size } → { uploadUrl, key, objectUrl } (public). `key` is the server-issued bare S3 key; the frontend echoes it back as `avatarKey` (do NOT reverse-parse it from objectUrl).
- S3 PUT: axios.put(uploadUrl, file, { headers: { 'Content-Type': file.type } })
- POST /api/auth/register { token, name, email, password, avatarUrl, avatarKey } → 201 user (NO token; redirect to /login?registered=1). 409 = email taken; 400 = invalid invite/photo. `avatarUrl` = presign objectUrl, `avatarKey` = presign key (both required).
- POST /api/auth/login { email, password } → 200 { token } (Phase 1). 401 = invalid credentials.
Stack (D-16/D-17/D-18): React + Vite, react-router-dom, axios, lucide-react, Inter font, CSS Modules. JWT in localStorage key `fademy_token`. Logout = removeItem + navigate to /login (stateless, D-13).
Existing folder state: MINIREDESOCIAL_FRONT already has its own git repo, .gitignore (node_modules/, dist/, .env), README.md, logo_fademy.png at the folder ROOT, and an empty src/assets/.gitkeep. NO package.json yet — scaffold into the existing folder, do not re-init git.
