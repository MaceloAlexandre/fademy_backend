  <action>
    Create FeedPage.jsx. State: posts ([]), cursor (null), hasMore (true), loading (bool, for first + next-page fetch), isRefreshing (bool), apiError (''). A fetchPage(reset) helper: if reset, treat cursor as null and replace posts; else append. Call api.get('/api/posts/feed', { params: { ...(cursor && !reset ? { cursor } : {}), limit: 20 } }); on success setPosts(reset ? data.posts : prev.concat(data.posts)), setCursor(data.nextCursor), setHasMore(data.hasMore); on error setApiError('Erro ao carregar feed. Tente novamente.'). Initial useEffect fetches the first page once on mount.

    Infinite scroll: a sentinel div ref at the bottom of the list with aria-hidden="true"; an IntersectionObserver (threshold 0.1) that, when the sentinel intersects AND hasMore AND not loading, calls fetchPage(false) with the current cursor. Re-create the observer when hasMore/loading change (per the PATTERNS code pattern). Disconnect on cleanup.

    Pull-to-refresh (D-03): touchstart/touchmove/touchend handlers on the list container that, when the user pulls down past a small threshold while scrollTop is 0, set isRefreshing true, reset cursor to null and call fetchPage(true), then clear isRefreshing (minimum ~300ms visual). Show a 28px Spinner at the top while isRefreshing.

    Render the six UI-SPEC states: initial loading (28px Spinner centered, aria-label "Carregando feed..."); list of PostCard; fetching-more Spinner (24px) below last card when loading && posts.length>0; empty state (heading "Nenhuma publicação ainda", body "Siga pessoas para ver posts delas aqui.", and a link/button "Buscar pessoas" navigating to /search) when not loading && posts.length===0 && !apiError; error ErrorBanner at top with the feed error copy; pull-to-refresh Spinner at top when isRefreshing. List container is display:flex column with no gaps (PostCard supplies its own border separator).

    Create FeedPage.module.css co-located with classes for the page container, list, sentinel, spinner wrappers, and empty state, using design tokens and the --space-3xl bottom clearance above the bottom nav.
  </action>
