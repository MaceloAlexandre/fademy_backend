## Spacing Scale

All tokens declared in `MINIREDESOCIAL_FRONT/src/styles/tokens.css`. Reference by CSS variable; do not redeclare.

| Token | Value | Usage |
|-------|-------|-------|
| `--space-xs` | 4px | Icon gaps, chip inner padding, category chip gaps |
| `--space-sm` | 8px | Compact element spacing, image grid gaps, comment item internal gap |
| `--space-md` | 16px | Default element spacing, card padding, compose field spacing |
| `--space-lg` | 24px | Section padding, feed horizontal padding |
| `--space-xl` | 32px | Section breaks |
| `--space-2xl` | 48px | Empty state vertical padding |
| `--space-3xl` | 64px | Page-level bottom clearance (above bottom nav) |

Exceptions:
- Bottom nav height: 56px (component constant, not a spacing token)
- Header height: 56px (component constant)
- Touch target minimum: 44px (`--touch-min`) — all tap targets: nav tabs, compose button, comment submit, post card tap area
- Image thumbnail grid height: 80px per thumbnail (fixed, not a spacing token)
- Comment input bar height: 56px (matches nav/header for visual rhythm)
- Post avatar in card: 40px diameter (matches UserResultCard pattern from Phase 3)

Accent is NOT used for: inactive nav icons, post card borders, image thumbnails, timestamps, or hover states on non-CTA elements.

### FeedPage

Route: `/` (replaces the "Feed em breve..." placeholder)

Layout:
- Full-width scrollable list of `PostCard` components
- No horizontal padding on list itself; `PostCard` has its own internal padding
- Pull-to-refresh: CSS-only spinner at top appears when `isRefreshing === true`; triggered on `touchstart`/`touchmove`/`touchend` — shows `Spinner` (28px, centered) at top of list for 300ms visual feedback minimum
- Infinite scroll: `IntersectionObserver` on a sentinel `<div>` at the bottom of the list; when visible and `hasMore === true`, dispatches fetch for next cursor page
- List container: `display: flex; flex-direction: column` — no gaps between cards (cards use border-bottom as visual separator)

States:
1. **Initial loading**: `Spinner` (28px) centered in page, `aria-label="Carregando feed..."`
2. **Feed with posts**: list of `PostCard` rows
3. **Fetching more (infinite scroll)**: `Spinner` (24px) centered below last card
4. **Empty feed**: empty state block (see Copywriting)
5. **Error**: `ErrorBanner` at top of list with retry guidance
6. **Pull-to-refresh in progress**: `Spinner` (28px) at top, above first card

### PostCard

Single post in the feed list. Tap anywhere navigates to `/posts/:id`.

Layout (vertical stack, internal padding `--space-md`):
- **Row 1 — Author header**: avatar (40px circle, `--radius-avatar`, `object-fit: cover`) | author name (label/14px/400, `--color-surface`) + timestamp (label/14px/400, `rgba(214,207,193,0.5)`) stacked vertically | (right-aligned, future: options menu — omit in Phase 4)
- **Row 2 — Text**: post body text (body/16px/400, `--color-surface`), multiline, no line clamp in feed (full text shown)
- **Row 3 — Images** (only if `imageUrls.length > 0`): horizontal scrollable strip of image thumbnails, each 80px × 80px, `border-radius: --radius-card`, `object-fit: cover`, gap `--space-sm`. Max 4 thumbnails (per D-04). Tap opens `/posts/:id` (no lightbox in Phase 4).
- **Row 4 — Link** (only if `linkUrl` is non-empty): link URL displayed as label/14px/400 text with `--color-accent` tint, `text-decoration: underline`, opens in new tab (`target="_blank" rel="noopener noreferrer"`)
- **Row 5 — Category chips**: horizontal scrollable row of chips. Each chip: label/14px/400, `--color-surface`, background `rgba(140,110,79,0.15)` (accent at 15% opacity), border `1px solid rgba(140,110,79,0.3)`, `border-radius: 12px`, padding `--space-xs --space-sm`
- **Row 6 — Footer bar**: comment count button (left-aligned). Button: `MessageCircle` icon (16px, `rgba(214,207,193,0.5)`) + count label (label/14px/400, muted), min-height 44px, background transparent, no border, tap navigates to `/posts/:id`

Card border: `border-bottom: 1px solid rgba(214,207,193,0.1)` (same separator pattern as UserResultCard)
Card background: transparent (dominant background shows through)
No card shadow in Phase 4.

### PostDetailPage

Route: `/posts/:id`

Layout:
- Top: single `PostCard` rendered at top (non-tappable, full detail view — same component, `isDetailView` prop disables navigation tap)
- Below: comment thread — all comments loaded at once (D-09), no pagination
- Bottom: fixed comment input bar

**Comment thread:**
- Each comment: avatar (32px circle) | author name (label/14px/600, `--color-surface`) + timestamp (label/14px/400, muted) | comment text (body/16px/400, `--color-surface`)
- Comment rows separated by `--space-md` vertical gap; no border separators
- Padding: `--space-md` horizontal, `--space-sm` vertical per item

**Fixed comment input bar (bottom):**
- `position: fixed; bottom: 56px; left: 0; right: 0; z-index: 90` (above bottom nav at 56px, so input sits at 56px from bottom)
- Height: 56px
- Background: `--color-secondary`
- `border-top: 1px solid rgba(214,207,193,0.15)`
- Contains: text input (flex: 1, background transparent, color `--color-surface`, font body/16px, placeholder "Adicionar comentário...") + send button (`Send` icon, 20px, `--color-accent`, min 44px × 44px touch target)
- Input has no border; focus ring on the bar container: `outline: 2px solid var(--color-accent-alt)` when input is focused
- `<main>` padding-bottom for this page: `calc(56px + 56px + var(--space-md))` (nav + comment bar + buffer)

States:
1. **Loading**: `Spinner` centered (post + comments loading together)
2. **Post loaded, comments loading**: render post, `Spinner` below for comments
3. **Loaded**: post + comment list
4. **No comments**: empty state below post (see Copywriting)
5. **Error (post)**: `ErrorBanner` full page
6. **Error (comment submit)**: `ErrorBanner` above input bar, dismissible
7. **Comment submitting**: send button shows `Spinner` (16px), input disabled

### ComposePage

Route: `/compose` (accessed via + nav tab, per D-12)

Full-page compose experience. On successful publish, navigates to `/` and resets feed cursor.

Layout (scrollable, single column, padding `--space-md`):
- **Page heading**: "Nova Publicação" (heading/20px/600, `--color-surface`)
- **Text area**: multiline textarea, background `--color-secondary`, color `--color-surface`, font body/16px/400, `border-radius: --radius-input`, `border: 1px solid rgba(214,207,193,0.2)`, padding `--space-md`, min-height 120px, placeholder "O que você está pensando?" — focus border `1px solid var(--color-accent)`
- **Image picker section**: label "Imagens (opcional)" (label/14px/600, `--color-surface`), then a row of up to 4 image slots. Each slot: 80px × 80px, `border-radius: --radius-card`. Empty slots show a `+` icon (Camera from lucide-react, 20px, `rgba(214,207,193,0.4)`) on `--color-secondary` background with dashed border `1px dashed rgba(140,110,79,0.4)`. Filled slots show thumbnail with a `×` remove button overlay (top-right, 20px × 20px, background `rgba(8,60,93,0.7)`, `X` icon 12px white). Slots are displayed horizontally with `gap: --space-sm`.
- **Link URL field** (visible to all roles; validated server-side for aluno — per D-06): label "Link (opcional)" (label/14px/600), input field using `FormField` pattern, placeholder "https://...", `type="url"`. If the user is `aluno` and enters a URL, the backend returns 403 — the error displays in `ErrorBanner` as "Sua função não permite postar links."
- **Category selector**: label "Categorias" (label/14px/600, `--color-surface`), required — at least one must be selected. Chips rendered for all available categories (fetched on mount from `GET /api/categories`). Selected chip: background `rgba(140,110,79,0.25)`, border `1px solid var(--color-accent)`. Unselected chip: background `rgba(214,207,193,0.08)`, border `1px solid rgba(214,207,193,0.2)`. Chip text: label/14px/400. Tap toggles selection. Multiple selections allowed.
- **Publish button**: `PrimaryButton` (reused), full width, label "Publicar", disabled when: text empty AND no images; or when category count is 0; or during submission loading
- **ErrorBanner**: appears above the Publish button when API returns an error

Back navigation: browser back (no explicit back button in compose page — users can tap Feed/Busca/Perfil tabs to escape).

States:
1. **Idle (empty form)**: Publish button disabled
2. **Form valid**: Publish button enabled
3. **Uploading/Submitting**: Publish button loading state (`Spinner` inline, button disabled), images uploading inline (each filled slot shows `Spinner` overlay)
4. **Error**: `ErrorBanner` above button, form re-enabled for retry
5. **Success**: navigate to `/` — no success toast in Phase 4

## Interaction States

### Loading
- Page-level loads: `Spinner` (28px) centered in content area with matching `aria-label`
- Button-level loads: inline `Spinner` (16px–20px) replaces or flanks label, button `disabled`
- Infinite scroll sentinel loading: `Spinner` (24px) centered below last card
- Image upload in compose: per-slot spinner overlay (see ComposePage)

### Error
- API errors: `ErrorBanner` component in relevant position (top of feed, above compose button, above comment input)
- 403 link-forbidden: `ErrorBanner` with "Sua função não permite postar links."
- Comment submit error: `ErrorBanner` slides in above fixed input bar
- Feed load error: `ErrorBanner` at top with "Erro ao carregar feed. Tente novamente."

### Empty
- Feed empty (no follows with posts): heading + body + CTA (see Copywriting)
- Post detail no comments: single line "Seja o primeiro a comentar." (body, muted, centered below post)
- No categories loaded: `ErrorBanner` in compose page, Publish button disabled

### Focus / Accessibility
- All interactive elements: `outline: 2px solid var(--color-accent-alt); outline-offset: 2px` on `:focus-visible`
- Buttons: `cursor: pointer`; disabled: `opacity: 0.5; cursor: not-allowed`
- Images: `alt` attributes required — post author name for avatars, "Imagem X de Y do post" for post images
- Bell icon in header: `aria-label="Notificações"`
- Comment input: `aria-label="Adicionar comentário"`
- Send button: `aria-label="Enviar comentário"`
- Category chips: `role="checkbox"` or `aria-pressed` to communicate selection state
- Feed sentinel div for infinite scroll: `aria-hidden="true"`
