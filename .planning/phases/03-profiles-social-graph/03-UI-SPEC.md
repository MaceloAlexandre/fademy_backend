## Component Inventory

New components to create for this phase. All use CSS Modules co-located with the component file. Reuse `PrimaryButton`, `FormField`, `ErrorBanner`, `Spinner` from Phase 2 without modification.

### AuthShell (replaces PostLoginShell in App.jsx)

Wrapper for all authenticated routes. Contains:
- Scroll-aware header (see below)
- `<main>` content area with bottom padding of 56px (nav height) + `--space-md`
- Bottom nav bar with 4 fixed tabs

**Header behavior:**
- Fixed to top, `position: fixed; top: 0; left: 0; right: 0; z-index: 100`
- Height: 56px
- Content: wordmark "Fademy" (heading 20px/600, `--color-surface`) on left; "Sair" button on right
- "Sair" button: ghost style — `border: 1px solid rgba(214,207,193,0.4)`, label text 14px/600, `--color-surface`, min-height 44px, padding `--space-xs --space-md`
- Scroll-aware: adds CSS class `.headerHidden` (transform: `translateY(-56px)`) when scrolling down; removes it when scrolling up. Transition: `transform 0.2s ease`. Detection via `useRef` + `useEffect` scroll listener on `window` tracking `lastScrollY` direction — not proximity to top.
- Background: `--color-dominant`, `border-bottom: 1px solid rgba(214,207,193,0.15)`

**Bottom nav bar:**
- Fixed to bottom, `position: fixed; bottom: 0; left: 0; right: 0; z-index: 100`
- Height: 56px
- Background: `--color-dominant`, `border-top: 1px solid rgba(214,207,193,0.15)`
- 4 tabs equally spaced (`display: flex; justify-content: space-around`)
- Each tab: icon (24x24, from lucide-react) + label (14px/400) stacked vertically, `gap: --space-xs`
- Active tab: icon and label use `--color-accent` (#8C6E4F)
- Inactive tab: icon and label use `rgba(214,207,193,0.5)` (muted beige)
- Touch target: each tab minimum 44px height

Tab definitions:

| Tab | Route | Icon (lucide-react) | Phase 3 state |
|-----|-------|---------------------|---------------|
| Feed | `/` | `Home` | Placeholder — renders "Em breve..." centered |
| Busca | `/search` | `Search` | Active |
| Notif | `/notifications` | `Bell` | Placeholder — renders "Em breve..." centered |
| Perfil | `/profile/me` | `User` | Active |

### SearchPage

Full-page component at `/search`. No secondary nav — search lives entirely in this page.

Layout:
- Sticky search input bar at top (below header): `position: sticky; top: 56px; z-index: 50; background: --color-dominant; padding: --space-md --space-lg`
- Search input: full width, `background: --color-secondary`, `border-radius: --radius-input`, `color: --color-surface`, `font-size: --text-body`, height 44px (`--touch-min`), left icon `Search` (16px, muted), placeholder "Buscar por nome..."
- Results list below the sticky bar, padded `--space-md --space-lg`
- Debounce: 300ms on `onChange`

States:
1. **Empty / no query**: heading "Buscar pessoas" (body, muted beige), no list shown
2. **Loading**: `Spinner` centered
3. **Results**: list of `UserResultCard` rows
4. **No results**: "Nenhum usuário encontrado" (body, muted), subtext "Tente um nome diferente" (label, muted)
5. **Error**: `ErrorBanner` with "Erro ao buscar usuários. Tente novamente."

Pagination: "Carregar mais" button (ghost style, full width) below last result when `page * limit < total`. Clicking appends next page results — NOT replacing, appending. Button label: "Carregar mais" / loading state shows `Spinner` inline.

### UserResultCard

Single row in search results.

Layout (horizontal): avatar (40px circle, `--radius-avatar`) | name (body/600) + role label (label/400, muted) | [follow state button] right-aligned

- Background: transparent (dark blue shows through)
- Separator: `border-bottom: 1px solid rgba(214,207,193,0.1)` between rows
- Tap anywhere on card navigates to `/profile/:userId`
- Follow button on card is a compact variant (see FollowButton below)

### ProfilePage

Accessible at `/profile/:userId` (other users) and `/profile/me` (own profile).

Layout (mobile, single column):
- Top section: avatar (80px circle, `border: 2px solid rgba(214,207,193,0.3)`, centered) | name (heading 20px/600, `--color-surface`, centered) | role badge (label 14px/400, muted, centered)
- Counters row (own profile or public/accepted): "X seguidores · Y seguindo" (label, muted) — hidden for private profile viewed by non-follower
- Bio (body 16px/400, `--color-surface`, max 3 lines, center-aligned) — hidden for private profile viewed by non-follower
- Privacy toggle (own profile only): `isPrivate` switch — label "Perfil privado" (label/400)
- Action row (other user's profile): FollowButton + BlockButton, side by side
- Posts section placeholder: "Posts aparecem aqui em breve" (body, muted) — hidden for private profile viewed by non-follower

Private profile visited by non-follower: shows avatar, name, role badge, and FollowButton only. Bio, counters, posts section are NOT rendered (not hidden via CSS — not returned by API or conditional render to `null`).

### FollowButton

Stateful button reflecting follow relationship. Receives `followStatus` prop (null | 'pending' | 'accepted') and `isPrivate` prop.

| State | Label | Style | Action on tap |
|-------|-------|-------|---------------|
| null + public | "Seguir" | PrimaryButton (accent fill) | POST follow → optimistic accepted |
| null + private | "Solicitar" | PrimaryButton (accent fill) | POST follow → optimistic pending |
| pending | "Solicitação enviada" | Ghost (border `--color-surface`, muted label) | Shows cancel confirmation sheet |
| accepted | "Seguindo" | Ghost (border `--color-accent`, accent label) | Shows unfollow confirmation sheet |
| blocked (either dir) | not rendered | — | — |

Cancel confirmation (pending state): inline text below button — "Cancelar solicitação?" + [Cancelar] [Confirmar] buttons. Not a modal. Confirm triggers DELETE.

Unfollow confirmation (accepted state): same inline pattern — "Deixar de seguir?" + [Cancelar] [Confirmar].

Loading state: any button shows `Spinner` (16px inline) replacing label while API call in flight. Button is `disabled` during call.

Compact variant (UserResultCard): same states, narrower padding (`--space-xs --space-md`), min-height 36px (card context, not page context — exception to 44px rule justified by row density).

### BlockButton

Visible on other user's profile when relationship is not blocked. Positioned to the right of FollowButton.

| State | Label | Style |
|-------|-------|-------|
| not blocked | "Bloquear" | Ghost, `border: 1px solid rgba(253,128,128,0.4)`, `color: --color-destructive`, min-height 44px |
| already blocked (user is the blocker) | "Bloqueado" | Ghost, muted, not tappable |

Block confirmation: inline confirmation below button — "Bloquear este usuário?" subtext "Seguidores mútuos serão removidos." + [Cancelar] [Bloquear] (Bloquear label uses `--color-destructive`). Not a modal.

## Interaction States

### Loading
- Page-level loads: `Spinner` component, centered in content area
- Button-level loads: inline `Spinner` (16px) replaces button label, button disabled
- Search debounce: no spinner during 300ms window; spinner shows only after 300ms if still loading

### Error
- API errors on follow/block actions: `ErrorBanner` slides in below the action row
- Search error: `ErrorBanner` replaces results list
- Profile load error: `ErrorBanner` centered in content area with "Erro ao carregar perfil. Tente novamente."

### Empty
- Own profile with no followers: counters show "0 seguidores · 0 seguindo"
- Search with no query: no list, instruction text shown
- Search with query and no results: "Nenhum usuário encontrado" + suggestion text

### Focus / Accessibility
- All interactive elements: `outline: 2px solid var(--color-accent-alt); outline-offset: 2px` on `:focus-visible`
- Buttons: `cursor: pointer`; disabled buttons: `opacity: 0.5; cursor: not-allowed`
- Images: `alt` attributes required on all `<img>` elements (avatar: user name)
- Nav tabs: `aria-current="page"` on active tab
