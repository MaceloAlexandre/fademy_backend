GET /api/users/:id response shapes:
  Private profile + non-follower:
    { id, name, avatarUrl, role, isPrivate: true, followStatus: null | 'pending' }
  Full profile (public or accepted or own):
    { id, name, avatarUrl, role, isPrivate, followStatus: null | 'pending' | 'accepted', followersCount, followingCount }
  Blocked in either direction: 404 { error: 'User not found' }

GET /api/users/me: same as GET /api/users/:id with viewerId === targetId → always full profile

PATCH /api/users/me body: { isPrivate: boolean }
Response: { id, name, avatarUrl, role, isPrivate }

POST /api/users/:id/follow
Response: 201 { status: 'accepted' | 'pending', followId }

DELETE /api/users/:id/follow

|----------|-------------|
| Browser → POST /api/users/:id/follow | User triggers follow from FollowButton; API enforces self-follow guard and block check |
| Browser → POST /api/users/:id/block | User triggers block from BlockButton; API enforces self-block guard and bilateral removal |
